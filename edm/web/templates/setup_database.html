Connect a database

EDM stores everything in Postgres with the pgvector and pgcrypto extensions. Once you submit, we test the connection, run all migrations, and seed the SOP library — no terminal commands.

Format: postgresql+psycopg://USER:PASS@HOST:PORT/DBNAME. The packaged Docker compose already provisions one — paste postgresql+psycopg://edm:edm@postgres:5432/edm if you started it that way.

Don't have Postgres running? (1-line Docker) 
docker run --name edm-pg -e POSTGRES_USER=edm -e POSTGRES_PASSWORD=edm -e POSTGRES_DB=edm -p 5432:5432 -d ankane/pgvector
docker exec edm-pg psql -U edm -d edm -c "CREATE EXTENSION IF NOT EXISTS pgcrypto; CREATE EXTENSION IF NOT EXISTS vector;"

Then come back and submit. The default URL above will work.

We validate the connection, confirm pgvector + pgcrypto, then apply all migrations and seed 5 SOP templates. Idempotent — safe to retry.
